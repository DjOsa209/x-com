# X-Ecommerce interface

Visual authority: saved Clipcat screenshots and DOM in research/clipcat-ui-2026-10-19. This is an implementation within that established reference, not an open visual exploration.

Operate mode. Desktop uses a pale 232px sidebar, white canvas, quiet gray separators, dark type and cyan-to-violet accents on the creation composer and primary action. Main workspace centers the product prompt composer, image attachment, generation modes, model/character selection and aspect/language controls. Other routes use consistent toolbars, tabs, tables and contextual detail panels. Chinese interface, English product brand.

Responsive: sidebar becomes a keyboard accessible drawer; toolbars wrap; the creation editor and result inspector stack; tables scroll within their own region. Maintain actual empty, unavailable, loading and error states. Use Lucide icons. Authored creative recipes are labeled templates and carry no fictional performance metrics. Source data and generated work appear only after actual actions.
