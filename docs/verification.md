# 本地验证记录

日期：2026-10-19。环境：macOS / Node.js 25.9 / MySQL Community Server 8.4.9。

- TypeScript 检查与 Vite 生产构建通过。
- 65 项自动测试通过，包括官方接口参数、长 ID/币种/零值、分页、加密、防重复提交、两阶段生成、重启中断、取消及发布/草稿箱状态区分。供应商响应使用合同测试桩，没有实际调用外部付费服务。
- 21 项真实 HTTP / MySQL 检查通过，包括新建和修改草稿、独立数据库连接读取、真实文件上传/下载字节、角色素材引用、缺少凭证、跨站写入和凭证不回显。测试自行清理创建的记录和文件。
- 68 项新增后台真实 MySQL / HTTP 检查通过，见 `npm run test:backend`：登录会话、RBAC、邀请注册与已有账号加入、跨团队素材/密钥/项目隔离、并发额度预留、幂等结算、孤立预留恢复、项目并发确认及部分失败重试、调度去重、worker/任务锁、支付 webhook 签名及重试。测试使用临时账号和空间，持有 MySQL worker 锁阻止任何测试任务调用外部服务，结束后自行清理。
- 13 项 S3 协议集成检查通过：真实 AWS SDK 对本机协议服务签名、PUT、HEAD、GET、COPY、DELETE；覆盖预留容量、上传确认幂等、文件头校验及旧上传链接不能覆盖已确认素材。没有使用真实云存储账户。
- 另有 3 项真实 fal SDK 的离线传输测试（计入上述 65 项），验证 HTTP 503 / 网络连接重置不会隐式重试付费提交，普通状态查询仍可用。
- 15 项视频链路真实 MySQL / FFmpeg 检查通过，见 `npm run test:video`。注入离线模型队列，验证不同尺寸/帧率、有声/无声视频的裁切、音轨补齐、拼接顺序、成片时长、短片段校验、成功片段复用、拼接失败恢复、无模型凭证重拼及重复重试幂等。全部测试记录/文件自动清理，无付费模型调用。
- 新增 19 项规划/流水线单测（计入上述 65 项）：四种切分策略、原生时长、时间轴错误/上限、模型配置、快照指纹、各阶段不明确提交不重发、轮询恢复、明确失败、人工核对与取消。
- 新增浏览器验收：内置浏览器预览 30 秒 / 4 段 / 8 次调用的离线计划，单段策略超过模型上限时显示错误并禁用确认；桌面与 390px 手机视口无整页横向溢出。未提交实际生成。验收用临时项目已清理，视口已恢复。
- 内置浏览器实际验证：模板填入创作要求、MySQL 草稿保存、未配置 fal.ai 时显示明确错误且不创建成功任务、弹窗连续输入不丢失焦点。

- 浏览器生成的桌面和手机截图保存在 `docs/screenshots/`。后台页面保留为内置浏览器交付页面。
