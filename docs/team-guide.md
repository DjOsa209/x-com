# 团队配置与使用指南

## 初始化与空间

1. 本机开启 `AUTH_REQUIRED=true`，创建首个管理员。旧本地资料仍属于 `local` 空间。
2. 在团队页创建空间，生成成员邀请链接，交给指定邮箱的成员注册/接受。管理员、操作员、只读成员权限由服务端执行。
3. 切换空间后分别配置密钥、预算和模型。新空间不会继承其他空间的密钥或素材。会话可在账号页单独撤销。
4. 管理员在运行与审计生成一小时有效的单次恢复链接，用户使用后全部旧会话失效；系统不代发邮件。

## 连接与预算

- EchoTik 要填写 API 专属用户名和密码，非 TikTok 登录密码。原生图片搜索无需 Gemini。语义图片识别和视频/评论分析需要 Gemini。
- Kie 与 fal 可同时配置；工作台分别选择渠道和模型。只配置 Kie 时，选择商品图首帧以避免需要 fal 首帧服务。
- 不支持独立角色的模型会拒绝角色参数；切换模型后处理界面的不兼容提示。
- 自动化页配置工作空间月度外部请求总预算，各规则另设单次/每日预算。请求失败也占用已预留预算，缓存命中不占用。时间边界为 UTC。
- 运行与审计检查数据库、FFmpeg、worker 心跳、存储、已配置连接和历史操作。凭据已填写并不代表已通过真实服务测试。

## 价格与确认

在项目的“报价规则”页填写供应商、模型、分辨率、每秒/每次费率、币种及来源。未知价格可保持空白，不能填写零冒充免费。价格更新后新报价使用新规则，旧确认仍保留原报价。选择模型的输出分辨率、首帧方式和分段策略后，再审阅生成计划与费用。

“应用经济预设”会选择 Seedance Mini、480p、商品图首帧，不覆盖全局默认配置。模型原生秒数可能高于最终片长，费用按原生请求估算。首帧生成、超分和实际供应商计费需按具体服务核对。内部积分和供应商成本分别记录。

## 五条工作路径

1. 选品：灵感搜索 → 详情趋势/评论回复 → 保存机会证据 → 分派负责人/备注 → 关联自有商品 → 创建项目。
2. 复刻：上传视频或填写链接 → 视频分析 → 点击时码核对 → 保存待审案例 → 案例中选择自有商品 → 编辑分镜 → 报价确认 → 查看各片段与成片。
3. 后期：成片打开后期 → 编辑或导入 SRT/VTT → 上传配音/BGM、调音量 → 选封面 → 本地生成新成片。单段重制/替换在项目“视频与片段”中操作，旧版本保留。
4. 发布：成片进入发布 → 文案/话题/商品项目关联 → 审核当前版本 → 下载 ZIP → 在平台手工发布 → 登记作品链接 → 授权同步或手工录入指标。官方直发/草稿路径只有资格启用后显示。
5. 自动化：选择扫描/监控/案例/效果模板 → 设置范围和预算 → 保存或立即运行 → 运行历史查看证据与错误 → 通知进入机会/案例或任务处置。

字幕文案不是已经识别出的音轨。默认使用模型原声；可手工编辑或导入字幕，配音需上传音频。市场预估 GMV 与自有作品指标分开；手工订单/GMV 必须记录来源，空字段保持未知。

## 故障处置

- 未配置：到当前工作空间的连接设置补充相应密钥。
- 预算停止：查看保留的证据，调整预算后手动发起新运行；不自动重发原研究。
- 供应商待核对：查看任务详情与请求 ID，先到供应商后台核对。有 ID 可刷新；无 ID 的未知提交不能直接重复。平台管理员在任务页填写核对说明后处置。
- 部分完成：下载成功片，重试失败项；重试和主动重制均先核对新增报价，确认后产生新任务。成功片段和可复用首帧保留。
- 素材无法删除：查看引用列表并归档，保证确认项目、排期和历史结果仍可用。
- 字幕方框：安装中文字体，Docker 自带 Noto CJK；本机静态 FFmpeg 会显式载入系统中文字体；其他安装可设置 `SUBTITLE_FONT_FILE` 和 `SUBTITLE_FONT_FAMILY`。检查 FFmpeg 支持 subtitles/libass。
- worker 心跳过期：独立部署检查 worker 日志和数据库；重启后未知外部提交进入人工核对，不自动重付费。
